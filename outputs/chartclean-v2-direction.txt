차트클린 웍스 버전 2: SS 구성 초안
작성일: 2026-10-09 KST
상태: 사용자 설명을 정리한 개편 방향. 운영 화면은 아직 변경하지 않음.

SS 목차
- 공통 양식
- 세팅
- 운영
- 병원 정보
기존 C콜·CA·운영 매뉴얼 등의 목차는 별도로 유지·정리한다.

공통 양식
병원 진료과 목록 → 환자 화면 / 병원 대시보드 / 소재.
각 진료과의 세 가지 화면은 우선 비워 둔다.
재활의학과의 소재만 기존 연세리셀 메시지 소재 엑셀에서 가져온다.
환자 화면과 병원 대시보드는 재활의학과도 우선 비워 둔다.

세팅
서비스 개시 전 준비 업무를 수행하는 곳.
이지행정, 서비스 준비, 초기 EMR 업로드를 병원별로 진행한다.
서비스 준비에는 해당 병원에 실제 적용할 서비스 범위를 표시한다.
오른쪽 상세 영역에서 진행 상태·완료 근거·참고 자료·변경 이력을 본다.
끝난 항목은 완료 상태로 남기고 이력을 보관한다.
모든 필수 세팅이 끝나면 세팅 완료 병원 목록으로 이동한다.
세팅 목록 아래에서 세팅 완료 병원을 별도로 확인할 수 있게 한다.

운영
세팅이 끝나 실제 서비스 중인 병원을 관리한다.
반복 EMR 업로드·자료 갱신과 서비스 운영 업무를 수행한다.
필요하면 완료된 세팅 이력을 열어 참고한다.
운영 기록과 과거 세팅 기록을 함께 보존하되 작업 목록은 구분한다.

병원 정보
병원 기본 정보·담당자·진료과·계약·EMR 제품·현재 적용 서비스를
별도 목차에서 조회·관리한다. 세팅 화면의 내부 탭에서 분리한다.
세팅과 운영은 동일한 병원 ID를 참조하고 병원 정보를 복제하지 않는다.

단계 전환
세팅 중 → 필수 항목 확인·완료 → 세팅 완료 → 운영.
현재 운영 중인 병원은 이관 기준을 확인한 뒤 운영 목록으로 분류한다.
과거 "설치됨" 표시만으로 전체 서비스 세팅 완료를 자동 판정하지 않는다.
완료 단계가 누락된 병원의 기존 이력을 없애지 않는다.

도입 순서
1. 기존 버전 복원 기준 및 전체 운영 소스 백업 확보.
2. 공통 양식과 진료과별 빈 화면, 재활의학과 소재 등록.
3. 병원 정보 독립 목차와 세팅·운영 분리.
4. 완료 항목 이력과 세팅 완료 병원 이동.
5. 검수 후 버전 2 배포 및 복원 가능한 배포 ID 등록.

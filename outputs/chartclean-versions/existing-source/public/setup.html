02

비밀번호 설정

접속에 사용할 비밀번호를 입력하고 설정 파일을 받으세요. 프로그램 설치 후 이 파일을 실행하면 비밀번호가 설정되고, 접속 번호와 비밀번호가 챙겨에 전송됩니다.

12~64자 · 영문, 숫자, ! @ # $ % ^ & * _ + = . ? - 사용 가능
다른 곳에서 쓰는 비밀번호는 피해주세요.

설정 파일로 이 병원의 비밀번호를 적용할 수 있습니다. 다른 사람에게 보내지 말고, 설정 후 파일이 남아 있으면 삭제하세요. 전송된 비밀번호는 챙겨에 암호화해 보관합니다.
현재 설정 EXE는 코드 서명이 없는 시험 배포 파일입니다. Windows에서 차단될 수 있습니다. 차단되면 보안 설정을 끄지 말고 챙겨 담당자에게 연락해 주세요.

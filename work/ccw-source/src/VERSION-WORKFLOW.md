# ChartClean Works 버전 운영

- 기존 버전: 현재 DO 화면. 원본 배포 `dpl_7ADQQ7PdoWtooSsSnA5pZv7J9MJg` 및 소스 백업은 별도 보존한다.
- 버전 2: `versions/v2`의 화면 복사본. `ccw32` + `kyunghwa` 두 조건을 모두 확인하고 로그인 후 `/v2`로 연결한다. 계정의 DB 역할은 변경하지 않는다.
- DO는 `/v2`에서 검수할 수 있으며 기본 접속 주소 `/`는 기존 화면이다.
- 고경화 복사본은 DO와 같은 메뉴와 조회 화면을 제공한다. 운영 데이터를 보호하기 위해 ccw32의 API 저장 요청은 거부한다. 계정 비밀번호 변경과 로그아웃은 그대로 지원한다.
- 이후 UI 수정은 `versions/v2/app`, `versions/v2/components`, `versions/v2/lib` 등에만 한다. 원본 `app/workspace.tsx`와 원본 구성요소를 직접 수정하지 않는다. 공통 인증·API·루트 전역 CSS의 변경은 양쪽에 영향을 주므로 별도 검토한다.
- V2 전용 스타일은 복사본의 CSS에서 수정한다. 루트 globals.css 수정이 필요한 경우 V2에서만 로드하는 별도 스타일로 분리한다.
- DO 반영 전 사용자가 검수하고 승인한다. `node scripts/promote-v2.mjs`로 변경 파일을 먼저 확인한다. 승인된 변경은 `node scripts/promote-v2.mjs --apply --approved`로 원본에 복사하고 빌드·배포한다. 새 파일은 별도 검토해서 원본에 추가한다. 이 명령은 배포하지 않는다.
- 전체 롤백은 별도 보관한 restore-version.ps1을 사용한다. 화면 코드만 되돌리며 운영 DB를 과거로 복원하지 않는다.

V2에는 임시 DO/직원 화면 전환과 직원 목차 7개를 제공한다. 전환은 표시만 바꾸고 실제 승인 권한은 로그인 계정으로 검증한다.
직원 계정 신청은 `/api/v2/staff-portal`에서 별도로 저장한다. 실제 DO는 `/v2/accounts`에서 승인한 뒤 외부 서비스에서 직접 계정 생성·초대하고 배정 정보를 등록한다. 다른 운영 데이터에 대한 ccw32 저장 제한은 유지한다.
전자결재는 온라인 결재시스템 작업의 기존 연결을 유지한다. 현재 직원별 실계정 연결은 별도 작업이며 테스트 결재 화면을 운영 결재 완료로 간주하지 않는다.
SS 버전 2는 병원 정보 / 세팅 / 운영 / 공통 양식으로 나눈다. 기존 setupGroup 병원 목록을 사용하며 `v2-hospital-profile:*`에 초안·확정본·완료 이력을 분리 저장한다. 초안 변경은 이전 확정본을 바꾸지 않는다.
병원 세팅 편집은 실제 DO 또는 ccw32 버전 2 계정만 가능하다. 화면 전환으로 권한을 얻지 않는다. 색상·원장명·사진·로고·진료과·5가지 서비스·소재를 지정하고, 근거 있는 세 가지 준비 완료 후 확정한다.
확정 화면 `/v2/hospitals/[id]/patient`와 `/staff`는 로그인한 검수자만 보는 구성 미리보기다. 외부 환자 인증·실제 병원 직원 로그인·EMR 분석·자동 발송은 이 개편으로 활성화하지 않는다.
EMR 최초/반복 파일은 비공개 저장소의 `v2-emr/`에 보관하고 `v2-hospital-emr:*`에서 병원별 메타데이터를 연결한다. 업로드는 검수 완료·실제 서비스 완료와 별도다. 반복 업로드는 확정 병원만 허용한다.
공통 양식은 재활의학과에 연세리셀 99개 소재·원고를 연결한다. 다른 진료과 및 공통 환자/대시보드 양식은 비워둔다. 원고는 의료진 미검수 상태를 그대로 표시한다.

2026-10-09 일일 업무 계획은 고경화 직원 로그인 기본 화면에 반영한다.

고경화 UI의 초록색 강조는 남색·회색으로 교체했다. 병원별 지정 색상은 유지한다.

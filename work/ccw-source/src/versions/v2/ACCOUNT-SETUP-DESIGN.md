# 직원 계정·병원 관리 화면

2026-10-09 사용자 수정 요청. 고경화 V2에만 적용한다.

계정 설정은 사무실에서 자주 여는 직원 도구다. 흰색·회색·남색과 기존 글꼴을 유지하고, 회사 서비스 목록을 중심에 놓는다. 네이버웍스·ChatGPT의 배정 계정과 상태를 실제 API로 표시한다. 오른쪽에 웍스 로그인 도구를 모은다. 신청·진행 현황은 결재 메뉴로 이동한다. 미배정은 사용 가능으로 표시하지 않는다.

SS 세팅은 병원 목록과 넓은 작업 영역으로 구성한다. 여섯 단계는 아이콘과 읽기 편한 글자로 표시하고, 중복된 내부 탭과 다음 서비스 버튼을 제거한다. 단계 이동은 하단 한 곳에서 한다. 준비 진행·자료·이력은 아래에 모아 입력 영역을 좁히지 않는다. 병원 정보에는 기존 계약·수금·EMR·원격 접속 기록을 표시한다. 로고·색상·사진과 제공 서비스 설정은 세팅에만 둔다. 미수 메모는 기존 정리본이며 실제 잔액을 추정하지 않는다. 비밀번호는 기존 권한 검사와 보기 버튼을 유지한다.

검증: 실제 배포의 계정 설정, SS 기본 정보·서비스·병원 정보를 확인한다. 문서함은 페이지 재요청 대신 출처·대상 검증을 거친 메시지로 전환한다. 결재 데이터와 API 응답은 캐시하지 않고, 공개 화면 파일만 5분 동안 재사용한다.

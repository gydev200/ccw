# 병원 세팅 화면

업무 화면의 목적은 병원을 선택하고 준비 항목을 순서대로 확인해 확정하는 것이다.
기존 ChartClean Works의 브랜드·상단 메뉴를 유지하고 병원 설정 영역만 재구성한다.

병원 목록 / 설정 본문 / 준비 진행의 세 영역을 분리한다. 본문은 기본 정보,
제공 서비스, 소재 연결로 나눠 한 번에 하나의 작업을 보여준다. 저장·확정은
페이지 상단의 같은 위치에 둔다. 긴 이력과 이전 세팅은 펼쳐서 확인한다.

흰 작업 영역, 밝은 회색 배경, 짙은 녹색 선택·확정 상태를 사용한다.
사진과 로고는 실제 등록 이미지 또는 미등록 아이콘으로 표시하고 만들어 넣지 않는다.
환자 화면은 휴대폰 비율, 직원 화면은 서비스 탭과 빈 환자 표로 구분한다.
데이터·권한·확정 조건·검수 상태는 디자인 변경으로 바꾸지 않는다.

작은 화면에서는 병원 목록을 높이가 제한된 영역에 두고 설정과 진행을 수직으로 배치한다.
가로 넘침은 단계 탭 내부에서만 허용한다. 이미지 파일 입력은 시각적으로 숨기되
업로드 동작은 보존한다.

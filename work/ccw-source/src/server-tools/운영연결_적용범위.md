# ChartClean 실제 기기 운영

직원 Windows 미니PC → ERP의 본인 조직·겸직 업무 → 회사 AI에 지시·수정 → 현재 맥북의 제작 폴더 → DO 판단함 → 송형석님 맥 에어의 전체 기록.

## 적용되는 기능
- ERP는 회사 업무·근태·휴가·지출·AI 제작 이력을 클라우드에 저장한다.
- mac_bridge.py는 현재 맥북에 전체 기록과 첨부 원본을 내려받는다. 토큰은 .connection.json에만 저장하고 소스·ERP 입력란에 넣지 않는다.
- 제작업무의 현재지시.json과 AI_지시문.md는 업무번호·결과 차수와 함께 내려온다.
- 결과전송_양식.json을 복사해 결과전송.json으로 저장하면 연결 프로그램이 전송한다. 최신 지시와 차수가 다르면 전송을 거절한다. 실제 파일을 생성하거나 AI 명령을 임의 실행하지 않는다.
- 회사 기록은 전체기록/latest.json, 첨부원본 폴더에 남는다. 매시간 기록 사본도 보존한다. 다른 기기로 복구할 때 기록과 첨부를 함께 옮겨야 한다.

## 직원 계정·맥 서버
- 직원마다 회사 소유 AI 계정과 별도 macOS 표준 계정을 사용한다. DO 계정을 공유하지 않는다.
- 실제 직원 macOS 계정과 Windows 원격 접속 설정은 아직 적용하지 않았다. macOS 원격 로그인은 SSH/SFTP 작업 경로이며 영상 편집 화면 공유와는 별도다. 동시 화면 작업 방식은 실제 편집 앱과 접속 도구를 확인한 뒤 정한다.
- 현재 동기화 폴더는 DO 사용자 전용이다. 직원별 계정을 만든 뒤 허용된 제작 폴더만 연결한다. 전체기록·첨부원본은 직원에게 공유하지 않는다.
- Apple 안내: https://support.apple.com/en-gb/guide/mac-help/mchlp1066/mac

## Windows
- windows_startup.ps1은 사용자 로그인 때 ERP를 여는 바로가기를 만든다. 출근 기록은 본인이 ERP에서 누른다.
- 인터넷 제한 권장: 표준 사용자 + 기기 관리 정책 + 허용 앱 + 업무 URL 허용 목록. ERP 웹페이지만으로 다른 브라우저·앱·쇼핑을 강제로 막을 수 없다.
- ERP, AI 로그인·서비스, 고객사·필수 업무 사이트는 허용한다. OS·SS도 서비스 조회·고객사 확인이 필요하다. 일반 검색은 기본 허용으로 확정하지 않고 업무 사이트 요청으로 판단한다.
- Edge URL 정책만 적용하면 다른 브라우저·앱까지 막히지 않는다. Windows 기기 관리와 실제 단말 검증이 필요하다. 현재 차단 완료로 표시하지 않는다.
- Edge 시작 페이지: https://learn.microsoft.com/en-us/deployedge/microsoft-edge-browser-policies/restoreonstartupurls

## 회수
ERP 접근 중지 → 맥 계정·원격 세션 차단 → 회사 AI·외주 계정 세션 회수 → 제작 원본·소스·설정 회수 → 회사 복구 수단 확인. ERP 버튼이 회수하는 것은 ERP 권한이며 외부 계정은 실제 서비스에서 회수한 근거를 기록한다.

## 맥 에어
기기 연결 전이다. 연결 시 읽기 전용 회수 경로를 따로 설정한다. 맥북의 서버 토큰을 직원이나 일반 공유 폴더에 전달하지 않는다.
